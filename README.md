# Portfólio de Gustavo Matias

Olá! Bem-vindo ao meu portfólio pessoal. Este projeto foi desenvolvido para apresentar meus principais projetos, habilidades e minha trajetória profissional.

## 🚀 Sobre o Projeto

Este é um site de página única (single-page) construído com tecnologias front-end puras, incluindo **HTML**, **CSS** e **JavaScript**. O objetivo principal é fornecer uma plataforma limpa e responsiva para exibir meu trabalho de forma clara e organizada.

### ✨ Funcionalidades

* **Seção Sobre Mim:** Um breve resumo sobre minha experiência e paixões.
* **Habilidades:** Uma lista visual das minhas principais competências técnicas.
* **Projetos:** Uma galeria dos meus projetos mais relevantes, com descrições e links para os repositórios.
* **Formação Acadêmica:** Detalhes sobre minha educação.
* **Certificados:** Provas de qualificação e cursos que completei.

## 💻 Tecnologias Utilizadas

* **HTML5:** Para a estrutura e marcação da página.
* **CSS3:** Para o estilo e layout.
* **JavaScript:** Para a lógica e a renderização dinâmica do conteúdo.

## ⚙️ Como Executar o Projeto

Como este projeto é um site estático, você pode abri-lo diretamente no seu navegador. Siga os passos abaixo:

1.  Clone este repositório para o seu computador:
    ```bash
    git clone [https://github.com/Gustavo-Matias19/nome-do-seu-repositorio.git](https://github.com/Gustavo-Matias19/nome-do-seu-repositorio.git)
    ```
2.  Navegue até a pasta do projeto:
    ```bash
    cd nome-do-seu-repositorio
    ```
3.  Abra o arquivo `index.html` em seu navegador.
